# GB28181 SIP 协议流程

## 1. 设备注册流程

```
┌────────┐                  ┌───────────┐
│  设备   │                  │ GBServer  │
└───┬────┘                  └─────┬─────┘
    │                             │
    │  REGISTER (无 Authorization) │
    │ ───────────────────────────> │
    │                             │
    │   401 Unauthorized          │
    │ <─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─│
    │                             │
    │  REGISTER (Digest)          │
    │ ───────────────────────────> │
    │                             │
    │   200 OK                    │
    │ <─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─│
    │                             │
```

注册周期（默认 3600 秒）内无心跳则视为离线。

## 2. 心跳保活

```
┌────────┐                  ┌───────────┐
│  设备   │                  │ GBServer  │
└───┬────┘                  └─────┬─────┘
    │                             │
    │  MESSAGE Notify Keepalive   │
    │ ───────────────────────────> │
    │                             │
    │     (GBServer 不回复)       │
    │                             │
```

- 心跳间隔 30 秒（可配置）
- GBServer 超时阈值 = 心跳间隔 × 倍数（默认 3 倍 = 90 秒）
- 超时后设备置为离线

## 3. 目录查询

```
┌────────┐                  ┌───────────┐
│  设备   │                  │ GBServer  │
└───┬────┘                  └─────┬─────┘
    │                             │
    │  MESSAGE Catalog Query      │
    │ <─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─│
    │                             │
    │  Response (SumNum=N)        │
    │ ───────────────────────────> │
    │                             │
    │  Response (SumNum=N, Num=K) │
    │    (多包时重复，直到 SumNum)  │
    │ ───────────────────────────> │
    │                             │
```

- `SumNum`：总包数
- `Num`：当前包中的设备数
- GBServer 收到后按多包聚合策略重组
